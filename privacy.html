Privacy policy

Last updated 19 November 2026

FYP Diary Housekeeper ("the bot") is a private Telegram bot used only by the members of one final-year-project group. This page explains what it handles and where that data goes.

What the bot collects

  • Messages that members send to the bot or tag it in: links, notes and written reflections.
  • Videos (vlogs) that members send to the bot.
  • Each member's Telegram user ID and handle, so the bot knows who sent what.
  • The date and time of each entry.

Telegram delivers the group's messages to the bot, but the bot only acts on and saves messages that tag it, reply to it or are bot commands. Other messages are ignored and never stored.

Google user data

The bot uses Google Drive, Google Docs and Google Sheets with the group owner's own Google account, only to create folders, upload the group's files, and write an index spreadsheet and journal documents in the group's Drive folder. It does not read or change other files, and it does not access any other person's Google account.

The bot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not used for advertising, is not sold, and is not transferred to anyone except as described on this page.

How data is processed

  • Files are stored in the group's own Google Drive folder.
  • Vlogs are transcribed into text on the bot's own server with an open-source speech-to-text model; the audio is not sent to any outside service.
  • Once every two weeks, that period's transcripts, notes and link titles are sent to an AI model through OpenRouter to write a short summary for the group. This is done with zero data retention, so the AI provider does not keep the material.
  • The server keeps temporary copies of videos only until they are filed, and a small database of entries that is backed up to the same Drive folder.

Sharing

The data is visible only to the group members and their project supervisor through the group's Drive folder and Telegram chat. It is not sold, rented or shared with anyone else.

Removing data

Members can undo their own last entry within 15 minutes using the bot's /undo command. Any member can ask the group owner to delete their entries or files at any time.

Contact

Questions about this policy: contact the maintainer through GitHub, @nzamree.
